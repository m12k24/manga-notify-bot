# 📚 Manga Release Notifier

お気に入りの漫画の最新刊発売日を、LINEで自動通知してくれるBotです。

## 🎯 これは何？

指定した漫画の発売日情報を取得し、毎朝自動でLINEに通知するシステムです。
AWS Lambda上で動作し、EventBridgeによって毎日自動実行されます。

## 💡 作った理由

漫画の発売日を把握しておらず、1話分を買い逃してしまった経験がありました。
「発売日をちゃんと管理したい」という個人的な課題に加えて、将来クラウドエンジニアを目指す中で、AWSのサーバーレス技術を実際に手を動かして学びたいと考え、このBotを開発しました。

## ⚙️ 仕組み

```
EventBridge（毎朝9:00 JSTに自動起動）
        ↓
AWS Lambda（Javaで実装）
        ↓
OpenBD API（書籍情報を取得）
        ↓
LINE Messaging API（通知を送信）
```

1. EventBridgeが毎朝決まった時刻にLambda関数を起動
2. LambdaがOpenBD APIに書籍情報（タイトル・発売日）をリクエスト
3. 取得した情報をもとに、LINE Messaging APIを使ってLINEに通知を送信

## 🛠️ 使用技術

| カテゴリ | 技術 |
|---|---|
| 言語 | Java 21 |
| クラウド | AWS Lambda, Amazon EventBridge |
| 外部API | OpenBD API（書籍情報取得）, LINE Messaging API（通知） |
| ビルドツール | Maven |
| ライブラリ | Gson（JSON解析）|
| バージョン管理 | Git, GitHub |

## 🔐 セキュリティ対応

LINEのアクセストークン・ユーザーIDはコードに直接書かず、AWS Lambdaの環境変数で管理しています。これにより、GitHub上にコードを公開しても機密情報が漏洩しない構成にしています。
